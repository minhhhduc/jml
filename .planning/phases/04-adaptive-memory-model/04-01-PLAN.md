       - `chunkRows <= MAX_CHUNK_ROWS` (constant = 100_000) else `IllegalArgumentException("chunkRows must be <= 100000, got " + chunkRows)`

    2. `modules/pandas/src/main/java/pandas/internal/CsvChunkReader.java` — `public final class` implementing `Iterator<DataFrame>` AND `AutoCloseable`. **Constructor signature:** `CsvChunkReader(Path path, ChunkedReadOptions opts) throws IOException`. Constructor body does, IN THIS ORDER:
       - Call `opts.validate()` to fail fast on bad options with path context
       - Open `Files.newBufferedReader(path, StandardCharsets.UTF_8)` (NOT `FileReader` — RESEARCH §Don't Hand-Roll row 1)
       - Read header line (skipping `skiprows` lines first via a single `readLine()` loop that mirrors Pandas.java:40-43)
       - Parse header: `String[] columns = headerLine.split(opts.sep)` (trim each)
       - If `opts.index_col != null` AND `index_col >= columns.length`: throw `IllegalArgumentException("index_col=" + index_col + " out of range for " + columns.length + " columns at " + path)`
       - Initialize look-ahead state: `next = null`, `exhausted = false`, call `advance()` to prime

       **`advance()` method** (private):
       - `List<double[]> rows = new ArrayList<>(opts.chunkRows)`, `List<String[]> strRows = new ArrayList<>(opts.chunkRows)`, `List<String> idxList = new ArrayList<>(opts.chunkRows)`, `boolean[] isStringCol` (sized `cols` after index_col removal)
       - Loop: while `rows.size() < opts.chunkRows` AND `br.readLine() != null`:
         - skip blank lines (`line.trim().isEmpty()`)
         - `String[] cells = line.split(opts.sep)`; for each cell, try `Double.parseDouble(cells[c].trim())`; catch → push to `strRows` and mark column as string
         - if `index_col != null`, push `cells[index_col].trim()` to `idxList`, else push `String.valueOf(localRowIndex)` to `idxList`
       - If `rows.isEmpty()` AFTER EOF: set `exhausted = true; next = null; return`
       - Else: build `Map<String, Series>` per chunk — for each column c: assemble `double[] colData`, `String[] colStr` (null if not string); `Series s = isStringCol[c] ? new Series(finalColumns[c], colData, colStr, indexArr) : new Series(finalColumns[c], colData, indexArr)`; `seriesMap.put(finalColumns[c], s)`. Then `next = new DataFrame(seriesMap)`. Columns order: drop `columns[index_col]` if `index_col != null`, else keep all.
       - Wrap any `IOException` from `br.readLine()` in `UncheckedIOException` (mirrors RESEARCH §Pattern 1 line 193).

       **`hasNext()` returns `!exhausted`**; **`next()` returns the cached look-ahead, calls `advance()` to prime the next one, throws `NoSuchElementException` if `exhausted`**.

       **`close() throws IOException`**: closes `br` if non-null; safe to call multiple times (null-check).

       **Javadoc preamble** (REQUIRED — per PATTERNS §Pattern 3): trust boundary = filesystem (caller path) → in-process DataFrame; STRIDE threats = T401 path traversal, T403 file handle leak, T405 OOM via chunkRows, T406 CSV formula injection (NaN-substituted); mitigations = `path.normalize()` (caller-side in Wave-2 Pandas.read_csv_streaming), AutoCloseable + try-with-resources, hard `chunkRows` ceiling, leading-char NaN substitution.

       Field defaults per WR-05: `private DataFrame next = null; private boolean exhausted = false;` (not just default — explicit).
