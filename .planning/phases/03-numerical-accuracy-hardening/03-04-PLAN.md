Print `[PERF] PASS add_elementwise.10_000_000 measured=37.20ms baseline=36.86ms (+0.9%)` style line for every check.

The accuracy gate is enforced by `mvn test -Dtest=AccuracyHardeningTest` (the JUnit hard-fail gate from Plan 03). The script does NOT run mvn test automatically — D-14 says "script-only gate, no failsafe plugin". Print `[ACCURACY] softmax_extreme_logits max_rel_err=1e-13 — run mvn -pl modules/sklearn -am test -Dtest=AccuracyHardeningTest to enforce` for each entry.
       - After the loop: if `$gateFailed` is true, `Write-Error 'Regression gate FAILED'; exit 1`. Otherwise `Write-Host '[3/3] PASS: all perf checks within tolerance.' -ForegroundColor Green`.
