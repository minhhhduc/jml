## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Maven Central → POC build | Third-party JNI artifacts enter the isolated benchmark. |
| `-Dbench.size` → allocation | Caller-controlled property could otherwise create oversized host/device allocations. |
| Java POC → JCuda JNI/cuBLAS | Native code and CUDA driver execute outside JVM memory safety. |
